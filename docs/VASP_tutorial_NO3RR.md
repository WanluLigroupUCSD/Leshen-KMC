## 0. VASP基础知识 / VASP Basics

### 0.1 什么是VASP / What is VASP

VASP (Vienna Ab initio Simulation Package) 是最常用的第一性原理电子结构计算软件，基于密度泛函理论（DFT）和平面波基组 + 赝势方法。

VASP is the most widely used first-principles electronic structure code, based on Density Functional Theory (DFT) with a plane-wave basis set and pseudopotential method.

核心思想 / Core idea: 求解Kohn-Sham方程，得到体系的电子密度、总能量和原子受力。
Solve the Kohn-Sham equations to obtain electron density, total energy, and atomic forces.

### 0.2 四个核心输入文件 / Four Core Input Files

VASP的每个计算需要**4个输入文件** / Each VASP calculation requires **4 input files**:

```
计算目录 / Calculation directory
├── INCAR      ← 计算参数 / Computational parameters (what to do, how to do it)
├── POSCAR     ← 原子结构 / Atomic structure (where are the atoms)
├── POTCAR     ← 赝势文件 / Pseudopotentials (how to treat each element)
└── KPOINTS    ← k点网格 / k-point mesh (how to sample reciprocal space)
```

| 文件 / File | 作用 / Role | 本项目来源 / Source in This Project |
|-------------|-------------|-------------------------------------|
| **INCAR** | 控制所有计算参数 / Controls all calculation settings | **已准备好** ✅ `/scratch/reny0b/zls/script/vasp/` |
| **POSCAR** | 定义晶胞和原子坐标 / Defines cell and atomic coordinates | **脚本自动生成** 🔧 `generate_all_structures.py` |
| **POTCAR** | 各元素的赝势 / Pseudopotentials for each element | **脚本自动生成** 🔧 `setup_potcar.sh` |
| **KPOINTS** | 布里渊区采样 / Brillouin zone sampling | **手动写(很简单)** ✍ 通常2-3行 |

### 0.3 POSCAR — 原子结构文件 / Atomic Structure File

POSCAR定义了**晶胞形状**和**原子位置** / POSCAR defines the **unit cell** and **atomic positions**.

```
Cu  N   O                            ← 第1行: 注释 / Comment (element names)
 1.0000000000                        ← 第2行: 缩放因子 / Scaling factor
   10.2248  0.0000  0.0000           ← 第3-5行: 晶胞矢量 / Lattice vectors (Å)
    0.0000 10.2248  0.0000           ←   a, b, c 三个方向
    0.0000  0.0000 35.4225           ←   c方向含真空层 / c includes vacuum
 Cu  N   O                           ← 第6行: 元素种类 / Element types (VASP5格式)
  64   1   1                         ← 第7行: 各元素原子数 / Atom counts per element
Selective dynamics                   ← 第8行(可选): 选择性弛豫 / Selective dynamics
Cartesian                            ← 第9行: 坐标类型 / Coordinate type (Cartesian/Direct)
  1.278  1.278 15.000  F  F  F      ← 原子坐标 + 是否弛豫 / Coords + fix/relax flags
  3.834  3.834 20.423  T  T  T      ← T=弛豫 F=固定 / T=relax F=fix
  3.834  3.834 21.209  T  T  T      ← 吸附物原子 / Adsorbate atom
  ...
```

**关键概念 / Key concepts**:
- **Cartesian vs Direct**: Cartesian给绝对坐标(Å), Direct给分数坐标(0-1) / Cartesian = absolute (Å), Direct = fractional (0-1)
- **Selective dynamics**: `T T T`表示该原子在x,y,z三方向均可弛豫, `F F F`表示固定 / T=free, F=fixed in x,y,z
- **元素顺序 / Element order**: 第6行的元素顺序**必须与POTCAR中的赝势顺序一致** / Must match POTCAR order!

**本项目中 / In this project**: 所有POSCAR由`generate_all_structures.py`自动生成，slab底部2层Cu已设为`F F F`。

All POSCARs are auto-generated by `generate_all_structures.py`; bottom 2 Cu layers are pre-set to `F F F`.

### 0.4 INCAR — 计算参数文件 / Calculation Parameter File

INCAR用**关键字=值**的格式控制计算的各个方面 / INCAR controls all aspects of the calculation using **keyword = value** format.

```fortran
# 结构优化示例 / Structure optimization example (INCAR_opt)

PREC    = Accurate    # 精度 / Precision mode
ENCUT   = 400         # 平面波截断能(eV) / Plane-wave cutoff energy
EDIFF   = 1E-5        # 电子步收敛标准(eV) / Electronic convergence
EDIFFG  = -0.05       # 离子步收敛: 负值=力(eV/Å) / Ionic convergence: negative=force

IBRION  = 2           # 离子弛豫算法 / Ionic relaxation: 2=CG, 5=freq, -1=static
NSW     = 300         # 最大离子步数 / Max ionic steps
ISIF    = 2           # 弛豫什么: 2=仅原子, 3=原子+晶胞 / What to relax: 2=ions, 3=ions+cell

ISMEAR  = 0           # 展宽方法: 0=Gaussian / Smearing: 0=Gaussian, 1=MP
SIGMA   = 0.05        # 展宽宽度(eV) / Smearing width

ISPIN   = 2           # 自旋极化: 1=无, 2=有 / Spin: 1=non, 2=polarized
IVDW    = 12          # 色散修正: 12=D3(BJ) / Dispersion: 12=DFT-D3(BJ)

LDIPOL  = .TRUE.      # 偶极修正(slab用) / Dipole correction (for slabs)
IDIPOL  = 3           # z方向偶极 / Dipole along z

LWAVE   = .TRUE.      # 保存波函数 / Save wavefunction (WAVECAR)
LCHARG  = .TRUE.      # 保存电荷密度 / Save charge density (CHGCAR)
```

**常用IBRION值 / Common IBRION values**:

| IBRION | 用途 / Purpose | 对应本项目 / This Project |
|--------|----------------|--------------------------|
| 2 | 结构优化(CG) / Structure optimization | Phase 0-4: 吸附物优化 |
| 3 | VTST优化器 / VTST optimizer | CI-NEB, Dimer |
| 5 | 频率计算(有限差分) / Frequency (finite diff) | Phase Freq: ZPE |
| -1 | 静态计算(不动原子) / Static (no ion movement) | GC-DFT单点 |

**本项目中 / In this project**: INCAR模板已在`/scratch/reny0b/zls/script/vasp/`中准备好，只需复制到计算目录并做少量修改（如气相分子删除偶极修正）。

INCAR templates are pre-configured at `/scratch/reny0b/zls/script/vasp/`. Just copy and make minor modifications (e.g., remove dipole correction for gas-phase molecules).

### 0.5 POTCAR — 赝势文件 / Pseudopotential File

POTCAR包含各元素的PAW赝势数据（PAW = Projector Augmented Wave）。

POTCAR contains PAW pseudopotential data for each element.

**关键规则 / Key rules**:
- POTCAR中各元素**顺序必须与POSCAR第6行一致** / Element order must match POSCAR line 6
- 多元素时，将各元素POTCAR**按顺序拼接** / For multi-element systems, concatenate in order
- 每个元素有多种赝势版本(Cu, Cu_pv, Cu_sv等) / Each element has multiple variants

```bash
# 示例: Cu + N + O 体系 / Example: Cu + N + O system
cat Cu/POTCAR N/POTCAR O/POTCAR > POTCAR

# 或用vaspkit自动化 / Or automate with vaspkit:
vaspkit -task 103
```

**本项目使用的赝势 / Pseudopotentials used**:

| 元素 / Element | POTCAR版本 / Version | ZVAL (价电子数) | ENMAX (eV) |
|-------|---------|------|------|
| Cu | PAW_PBE Cu | 11 (3d¹⁰4s¹) | 295 |
| N | PAW_PBE N | 5 (2s²2p³) | 400 |
| O | PAW_PBE O | 6 (2s²2p⁴) | 400 |
| H | PAW_PBE H | 1 (1s¹) | 250 |

ENCUT应≥max(ENMAX)×1.13 = 400×1.13 ≈ 450 eV → 我们用ENCUT=450 eV。

ENCUT should be ≥ max(ENMAX) × 1.13 → we use ENCUT = 450 eV.

**本项目中 / In this project**: `setup_potcar.sh`自动读取POSCAR中的元素顺序，按序拼接POTCAR。

`setup_potcar.sh` automatically reads element order from POSCAR and concatenates POTCARs accordingly.

### 0.6 KPOINTS — k点采样文件 / k-Point Sampling File

k点网格决定了倒空间的采样密度。更密的k点网格→更精确但更贵。

The k-point mesh determines reciprocal-space sampling density. Denser mesh → more accurate but more expensive.

```
K-points                     ← 第1行: 注释 / Comment
0                            ← 第2行: 0=自动生成 / 0 = automatic
Gamma                        ← 第3行: Gamma中心 / Gamma-centered mesh
2 2 1                        ← 第4行: 网格密度 Nx×Ny×Nz / Mesh density
0 0 0                        ← 第5行: 偏移 / Shift (usually 0 0 0)
```

**本项目的k点 / k-points in this project**:

| 体系 / System | k-points | 原因 / Reason |
|-------|----------|--------|
| 气相分子 / Gas-phase | 1×1×1 (Gamma only) | 大box，无周期性需求 / Large box, no periodicity needed |
| p(4×4) slab | **2×2×1** | 表面计算, z方向无需k点 / Surface calc, no k-points in z |

**为什么slab的z方向k=1? / Why k=1 along z for slabs?** 因为z方向有真空层(15 Å)，电子态在z方向不具周期性。

Because the vacuum layer (15 Å) breaks periodicity along z.

### 0.7 主要输出文件 / Key Output Files

VASP运行后生成多个输出文件 / VASP generates multiple output files after running:

| 文件 / File | 内容 / Content | 常用提取 / Common Extraction |
|-------------|----------------|------------------------------|
| **OUTCAR** | 详细计算日志 / Detailed log | 能量, 力, 收敛状态 / Energy, forces, convergence |
| **CONTCAR** | 优化后结构 / Optimized structure | 用作下一步的POSCAR / Use as POSCAR for next step |
| **OSZICAR** | 电子+离子步摘要 / SCF + ionic summary | 快速查看收敛 / Quick convergence check |
| **WAVECAR** | 波函数 / Wavefunction | 续算加速 / Restart acceleration |
| **CHGCAR** | 电荷密度 / Charge density | 续算, DOS分析 / Restart, DOS analysis |
| **LOCPOT** | 静电势 / Electrostatic potential | GC-DFT功函数提取 / Work function (needs LVHAR=.TRUE.) |
| **vasprun.xml** | XML格式全部数据 / All data in XML | pymatgen/ASE解析 / Parsing with pymatgen/ASE |

**最重要的能量提取 / Most important energy extraction**:

```bash
# "energy(sigma->0)" = E₀, 即不含展宽误差的总能 / Total energy without smearing error
grep "energy(sigma->0)" OUTCAR | tail -1
# → energy(sigma->0) =   -XXX.XXXXX

# 检查收敛 / Check convergence
grep "reached required accuracy" OUTCAR
# 有输出 = 已收敛 / Output present = converged
```

### 0.8 VASP计算的一般流程 / General VASP Workflow

```
1. 准备4个输入文件 / Prepare 4 input files
   POSCAR + INCAR + POTCAR + KPOINTS

2. 提交作业 / Submit job
   sbatch cp-vasp.sh

3. 等待完成 / Wait for completion
   squeue -u $USER          # 查看队列 / Check queue

4. 检查收敛 / Check convergence
   grep "reached required accuracy" OUTCAR

5. 提取结果 / Extract results
   - 能量: grep "energy(sigma->0)" OUTCAR
   - 结构: CONTCAR → 用作下一步POSCAR / Use as next POSCAR
   - 力:   grep "FORCES:" OUTCAR

6. 后续计算 / Next calculation
   cp CONTCAR next_calc/POSCAR
   # CONTCAR是优化后结构，可直接作为下一步输入
   # CONTCAR is the optimized structure, directly usable as next input
```

### 0.9 Selective Dynamics — 固定原子 / Fixing Atoms

在slab计算中，底层原子模拟块体(bulk)环境，需要固定不动:

In slab calculations, bottom-layer atoms represent the bulk environment and should be fixed:

```
Selective dynamics              ← 在原子数行后添加此行 / Add after atom count line
Cartesian
  1.278  1.278 15.000  F F F   ← 底层Cu: 固定 / Bottom Cu: fixed
  3.834  3.834 15.000  F F F
  0.000  0.000 16.808  F F F   ← 第二层Cu: 固定 / 2nd layer Cu: fixed
  ...
  0.000  0.000 20.423  T T T   ← 顶层Cu: 弛豫 / Top Cu: relaxed
  3.834  3.834 21.209  T T T   ← 吸附物N: 弛豫 / Adsorbate N: relaxed
  3.834  3.834 22.359  T T T   ← 吸附物O: 弛豫 / Adsorbate O: relaxed
```

本项目 / This project: 4层Cu slab → 底2层F F F（固定）, 顶2层+吸附物T T T（弛豫）。由`generate_all_structures.py`自动设置。

4-layer Cu slab → bottom 2 fixed, top 2 + adsorbates relaxed. Auto-set by script.

## 9. Phase GC-DFT: 恒电势活化能 / Constant-Potential Barriers

### 9.1 原理 / Principle

```
Ω(U) = E(Nₑ) + ΔNₑ × Φ           巨正则自由能 / Grand canonical free energy
U_SHE = Φ − 4.6                    电位 / Electrode potential
Ω(U) = aU² + bU + c                二次拟合 / Quadratic fit (R² > 0.99)
Ea(U) = Ω_TS(U) − Ω_IS(U) + ΔZPE  恒电势活化能 / Constant-potential barrier
```
