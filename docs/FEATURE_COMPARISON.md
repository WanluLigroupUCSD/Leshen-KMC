# Leshen-KMC vs Zacros 4.0 功能对比报告

> 生成日期: 2026-03-21

---

## 1. 总览

| 维度 | Leshen-KMC | Zacros 4.0 |
|------|-----------|------------|
| 语言 | Python + Rust | Fortran 90 |
| 定位 | 电催化 KMC (N₂还原) | 通用表面催化 KMC |
| 晶格 | 简单立方 (1D/2D/3D) | 三角/矩形/六方/自定义/显式图 |
| 物种 | 单齿 (single-site) | 多齿 (multidentate) |
| 能量学 | 固定活化能 + DFT插值 | 团簇展开 (Cluster Expansion) |
| 速率 | Arrhenius / TST / Butler-Volmer | Arrhenius + 7参数前因子 + BEP |
| 并行化 | 无 | MPI + OpenMP |

## 3. Leshen-KMC 独有优势

1. **电化学KMC**: Butler-Volmer PCET速率、电位依赖活化能、极化曲线
2. **MKM+KMC双模式**: 同一反应网络可用均场ODE或随机KMC求解
3. **DFT数据集成**: 三次样条/二次拟合Ea(U)，JSON导入，R²质量指标
4. **参数扫描**: 内置电位扫描和温度扫描
5. **分析工具**: 选择性、表观活化能、Campbell速率控制度
6. **灵活API**: 字符串表达式求值、运行时参数调整、kmos兼容
7. **双语言架构**: Python (研究友好) + Rust (高性能CLI)
8. **3D晶格支持**: Zacros仅支持2D

## 4. 关键缺失特性 (按优先级排序)

### 🔴 关键 (Critical) — 限制通用性的核心功能

| 优先级 | 特性 | 影响 | 实现难度 |
|--------|------|------|---------|
| 1 | **团簇展开能量学** | 无法模拟覆盖度依赖的侧向相互作用 | 高 |
| 2 | **多晶格类型** (三角/六方/自定义) | 限制可模拟的表面体系 | 中 |
| 3 | **多齿物种** | 无法表示桥位/穴位吸附 | 中-高 |

### 🟡 高 (High) — 显著提升功能的特性

| 优先级 | 特性 | 影响 | 实现难度 |
|--------|------|------|---------|
| 4 | **位点类型系统** | 无法区分顶位/桥位/穴位 | 中 |
| 5 | **刚度缩放** | 刚性体系效率极低 | 中 |
| 6 | **BEP关系** | 手动输入每个活化能，无法自动调整 | 低 |
| 7 | **子图同构模式匹配** | 仅支持平移offset匹配 | 高 |
| 8 | **OpenMP并行** | 大体系性能瓶颈 | 中 |

### 🟢 中 (Medium) — 有用但非必需

| 优先级 | 特性 | 影响 | 实现难度 |
|--------|------|------|---------|
| 9 | First Reaction Method | 算法选择 | 中 |
| 10 | 自动可逆反应配对 | 便利性 | 低 |
| 11 | 晶格快照输出 | 可视化 | 低 |
| 12 | 检查点/重启 | 长时间模拟恢复 | 中 |
| 13 | TPD模拟 | 特定实验条件 | 中 |
| 14 | 灵活输出触发器 | 输出控制 | 低 |

## 5. 推荐开发路线图

### 阶段1: 核心能量学 (最高优先)
- 实现**团簇展开**框架 (多位点能量团簇定义、能量增量更新)
- 添加**覆盖度依赖速率**

### 阶段2: 晶格通用化
- 支持**多种晶格类型** (三角、六方)
- 添加**位点类型**系统
- 支持**多齿物种**

### 阶段3: 算法优化
- 实现**刚度缩放**
- 添加**BEP关系** (proximity factor ω)
- 实现**First Reaction Method** + 二叉堆

### 阶段4: 可扩展性
- 添加**OpenMP**线程支持 (Rust rayon)
- 实现**检查点/重启**
- 晶格快照输出

---

## 6. 结论

Leshen-KMC在**电化学KMC**领域具有独特优势（Butler-Volmer速率、极化曲线、MKM双模式），这是Zacros 4.0不具备的。但在**通用表面催化KMC**方面，Leshen-KMC缺少三个关键特性：团簇展开能量学、多晶格类型、和多齿物种。补全这些特性将使Leshen-KMC成为兼具电化学特色和通用催化功能的KMC平台。
